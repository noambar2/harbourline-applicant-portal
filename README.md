# Harbourline University — Applicant Portal

A mobile-first applicant portal mockup for **Harbourline University**, a fictional
Australian university. Applicants use it to track their tasks, campus bookings,
learning modules, messages and enquiries on the way to their first semester.

This project is an English (en-AU), left-to-right adaptation of an existing
mobile-first applicant portal mockup. All people, places and data are invented.

## Stack

- React + Vite
- Tailwind CSS
- shadcn/ui components (Radix UI) and lucide icons

## Running locally

```sh
pnpm i
pnpm dev
```

## Deployment

The site is built with Vite and deployed to GitHub Pages under
`/harbourline-applicant-portal/` (see `.github/workflows/deploy.yml`).

## Design system

- `guidelines/Guidelines.md` — design-system rules, tokens and components.
- `design/figma-tokens/` — Figma variable files generated from the code tokens.
